# Tools and permissions

Generated by `python scripts/gen_tool_docs.py` from the tool registry.

Risk levels: READ_ONLY < SAFE < SENSITIVE < DANGEROUS < BLOCKED. A tool's level may be refined per call (e.g. the terminal classifies each command; `write_file` is DANGEROUS when overwriting). "Confirm" means the tool always asks regardless of policy. Policy per category lives in `backend/config/permissions.yaml`.
